# Star Component






This project is a responsive and interactive Star Rating Component built using React, Tailwind CSS, and JavaScript. Users can rate an item by hovering over stars, with the stars dynamically filling up based on the user's selection.



## Features

- Dynamic star highlighting on hover.
- Built with React for efficient rendering.
- Styled using Tailwind CSS for a modern, responsive UI.
- Easy to integrate into any project.

## Technologies Used

- React - For building the component-based UI.
- Tailwind CSS - For styling the component.
- JavaScript - For logic and interactivity.


## Installation

1.Clone the respository:

```sh
git clone https://github.com/tr-Kalyan/front_end_projects.git
```

2.Navigate to the project directory:
```sh
cd front_end_projects/docs/star_component
```
3.Install the dependencies and devDependencies and start the server.

```sh 
npm install
```

4.Start the development server
```sh
npm run dev
```

5.Open your browser and visit
```sh
http://localhost:5173
```

How It Works

- The Star.jsx component renders a set of stars.

- On hover, stars up to the hovered index get highlighted by adding a CSS class.
- Based on the stars rating, text will be displayed dynamically

- Tailwind CSS is used for quick and responsive styling.
